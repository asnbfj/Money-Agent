# Money Agent 前端

基金项目部工作台。支持从支付宝持仓截图导入基金、保存本机持仓、每分钟刷新净值/盘中估值；智能分析入口会调用项目内的 `FinancialAgent` 并显示行情、统计和文字报告。尚未导入前，组合概览和持仓表展示的是示例数据。

## 启动

在项目根目录运行：

```bash
python3 -m money_agent.web
```

打开终端输出的本地地址（默认 `http://127.0.0.1:8765`）。服务默认监听本机；截图 OCR 使用 macOS Vision 在本机处理，图片不会上传到外部服务。导入持仓只保存基金代码、名称、份额和成本净值至项目根目录下被 Git 忽略的 `.money-agent-data/holdings.json`。OCR 需要 macOS 和 Swift 工具链；行情功能需要安装 `requirements.txt` 中的项目依赖。如已配置 `.env`，服务会读取其中的 LLM 设置；未配置 LLM 时 Agent 会使用规则化文案模式。

估值默认每 30 秒刷新一次（可在持仓表右上角改成 15 / 60 秒或手动刷新，页面在后台时暂停）。服务端行情缓存默认 20 秒，可用 `MONEY_AGENT_QUOTE_CACHE` 调整。接口和基金销售平台的估算口径可能不同；盘中估值仅供参考。截图识别结果可在确认导入前手动修正。

## 盘中估值怎么更新

参考了 [fund-baby](https://github.com/zhengshengning/fund-baby) 的做法：

- **估值**：东方财富基金估值（与天天基金同源），给出盘中估算净值和涨跌幅。
- **正式净值备用源**：东方财富取不到数据，或交易日收盘后还没更新当日净值时，改用腾讯财经 `qt.gtimg.cn` 的正式净值。当日净值一公布，涨跌就从“估算”切换为“实际”。
- **口径切换**：当天有估值、当日净值还没公布 → 用估值（包括收盘后到净值公布前这段时间）；否则用最近正式净值。
- **交易日判断**：用上证指数最近的行情日期判断今天是否开市，能识别法定节假日；刷新状态会显示「交易中 / 午间休市 / 已收盘 / 今日休市」。
- **当日分时**：腾讯 `getSsgz` 提供每分钟估值，按持有份额加总成组合的今日估值曲线（`GET /api/intraday`，单只基金 `GET /api/intraday/<代码>`）。

如需修改地址，可设置 `MONEY_AGENT_HOST` 或 `MONEY_AGENT_PORT`。

## 截图导入是怎么工作的

支付宝「我的持有」列表不显示基金代码，只有名称、金额、日收益和持有收益。导入流程是：

1. 本机 OCR（macOS Vision）识别文字和位置，按行、按列还原每张持仓卡片；界面标签和「买入中」等状态会被忽略。
2. 用基金名称表（akshare，缓存 12 小时）匹配代码：精确匹配、被省略号截断的名称按前缀匹配、OCR 错字用模糊匹配，每只基金最多给 3 个候选。
3. 份额 = 持有金额 ÷ 最近正式净值；成本净值 = (持有金额 − 持有收益) ÷ 份额。
4. 在确认表里核对匹配结果；改代码会重新查询净值并重算，确认后才写入持仓。

截图里直接带 6 位代码的平台（如天天基金）仍按代码识别。解析逻辑的单元测试：`python3 -m unittest discover -s tests`。
