# Money Agent 前端

基金项目部工作台。支持从支付宝持仓截图识别并导入基金、保存本机持仓、每分钟刷新净值/盘中估值；智能分析入口会调用项目内的 `FinancialAgent` 并显示行情、统计和文字报告。尚未导入前，组合概览和持仓表展示的是示例数据。

## 启动

在项目根目录运行：

```bash
python3 -m money_agent.web
```

打开终端输出的本地地址（默认 `http://127.0.0.1:8765`）。服务默认监听本机；截图 OCR 使用 macOS Vision 在本机处理，图片不会上传到外部服务。导入持仓只保存基金代码、名称、份额和成本净值至项目根目录下被 Git 忽略的 `.money-agent-data/holdings.json`。OCR 需要 macOS 和 Swift 工具链；行情功能需要安装 `requirements.txt` 中的项目依赖。如已配置 `.env`，服务会读取其中的 LLM 设置；未配置 LLM 时 Agent 会使用规则化文案模式。

估值每 60 秒刷新一次，使用公开行情接口返回的盘中估算或最新官方净值。接口和基金销售平台的估算口径可能不同；盘中估值仅供参考。截图识别结果可在确认导入前手动修正。

如需修改地址，可设置 `MONEY_AGENT_HOST` 或 `MONEY_AGENT_PORT`。
